About
mu2edaq File Reaper v{{ app_version }}

Policy-driven disk cleanup for the Mu2e DAQ. Each configured area is measured on every scan; when used space crosses a tier threshold the tier's policy builds an ordered queue of eligible files and acts on it until the tier's stop mark is reached:

  • warning — by default LRU-Compress: compress least-recently-accessed files.
  • critical — by default LRU-Delete: delete least-recently-accessed files.
  • full — by default Age-Delete: delete the oldest files by modification time.

Every decision (queue add, action, tier change, pause, exclusion, token) is written to an audit history that the History page, the JSON API and the mu2edaq-reaper command line tool can query. Exclusions protect files; pause / disable stop actions per area; dry-run mode plans without touching anything.

Sibling of mu2edaq Disk Watcher; the two share their look and API conventions.
